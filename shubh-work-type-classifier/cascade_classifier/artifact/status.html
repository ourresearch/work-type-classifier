Whatthis is

A small, auditable classifier that corrects OpenAlex's type field. We removed the circular features (OpenAlex's own oa_type/is_paratext), kept raw Crossref signals, and engineered ~15 interpretable features. The deployable is a deterministic rule cascade (clean types, exported to Spark SQL) feeding a depth-6 decision tree for the fuzzy article↔editorial/review residual. Headline metric is the article-boundary scorecard, not overall accuracy.

DeployHIGH-confidence Crossref-trust tier

The Spark-SQL corrector (worktype_rules.sql) overrides OpenAlex's type only when an independent signal fires, otherwise it keeps the current label. Its top tier trusts Crossref's own type over OpenAlex's — every rule below is ≥86% precise on the full 12,123-work gold set. preprint is now subtype-gated: raw posted-content is only 71% (the rest is supplementary-materials/abstracts), so requiring Crossref subtype=preprint lifts it to 99%.

Deep-diveparatext — a vocabulary type (iteration I6)

Paratext errors are decided by title words the de-leaked model couldn't see (it had only title_len). Examples from the held-out set:

directiontitleopus reasonwhy the model missed
paratext → articleBIM volume 13 issue 1 Cover and Back matter“explicitly says Cover and Back matter”model had no title-token feature — only title_len
paratext → articleContributors“front/back-matter packaging record”title_len(1) ≈ a short article
paratext → articleExpediente“journal masthead / front-matter”non-English masthead, invisible to title_len
article → paratextpina bausch(real article in a dance magazine)title_len(2) wrongly flagged paratext

We ranked title tokens by precision×support (raw information gain just surfaces stopwords) and turned the winners into one anchored, deterministic title:paratext rule — 0.99 precision, info-gain-selected:

I6 result: paratext precision 0.56 → 0.88 (the rule kills the title_len false alarms on short real articles). Gini/info-gain are already the tree's split criterion — the fix was giving them the right binary feature, not changing the criterion.
I7 result: referencing the OpenAlex production detective (openalex-guts work_type_detective.py) added a richer title vocabulary and the structured cr_type=journal-issue signal — the non-title signal that breaks the vocabulary ceiling. It now sits in the HIGH-confidence Crossref-trust tier above: journal-issue → paratext, 91.7% precision (n=84) on the full gold set. Paratext recall rises (test 0.32→0.36; the rule alone is 0.99 precision / 0.57 recall gold-wide) with precision held at 0.91.
